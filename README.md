# 一键统一宋体（YJST）

日期：2026-10-13
状态：v0.2.5 已修复大字体清理顺序并构建，目标 CAD 原图待复测

将当前 DWG 的普通文字样式和可处理的局部字体统一为宋体（SimSun），保留其他格式。不自动保存，不修改 `SECURELOAD`、`FONTALT`、`FONTMAP` 或 `LISPSYS`。

## 使用

1. `APPLOAD` 加载 **`output/gb2312/one-click-simsun.lsp`**，确认提示版本为 **v0.2.5**。
2. 输入 `YJST` 回车，查看中文摘要和日志路径。详细结果可输入 `(princ *OCS:LastReport*)` 查看。
3. 成功转换后，一次 `U` 撤销本次修改；无需修改时不会新增撤销分组。

根目录文件是 UTF-8 开发源码；目标 CAD 使用 GB2312 交付版。若之前从其他目录加载，请替换那份文件并重新 `APPLOAD`，以命令提示的版本号为准。

## 本次修复

- 新日志证明：设置宋体后的清大字体 `entmod` 也会重置字体描述符。v0.2.5 将清理移到字体设置之前，大字体本就为空时不回写；试写与正式修改共用同一顺序。
- 接受文件绑定或双文件名均空的字体描述符绑定；两种方式都必须读回宋体、字符集 134、pitch/family 22，并保留原粗斜体。错误文件、空字体族、替代字体和接口异常仍停止并回滚。
- 设置宋体后只读核对 DXF、COM、字体参数和非字体参数，临时试写及正式修改均保留再生检查。新增 `BIGFONT_CLEAR`、`BIGFONT_CHECK`，并记录 `entmod` 调用及原始错误。

本次证据、修复和验证见 [大字体清理顺序修复](docs/大字体清理顺序修复-2026-10-13.md)。

## 排查日志

- 每次运行自动生成独立的 `YJST-*.log`，开始和结束均显示完整路径。输入 `YJSTLOG` 可再次查看路径。
- 日志记录环境与图纸名、扫描阶段、块名、对象类型、句柄、图层、接口调用前后、原始错误、回滚和最终状态；每条记录关闭文件落盘，保留异常前最后一个调用。
- 修正 `TDbSymbMultiLeader` 被名称子串误判为普通引线的问题；这类未适配的专业对象保留原状，计入“未覆盖”，存在未覆盖时报告“部分完成”。

日志优先写入 CAD 的 `TEMPPREFIX`，失败后尝试系统 `TEMP` 和图纸目录。每次新建，保留之前的文件；文件名不会被 CAD 的临时文件机制自动删除。日志写入失败时，`YJSTLOG` 显示最近 40 条内存记录及日志错误，不覆盖原始业务错误。

日志优先使用 UTF-8；旧 CAD 不支持编码参数时自动使用引擎原有文本编码，并在日志开头标记 `CAD-legacy`。无需修改 CAD 系统变量。

**若仍报错，发送命令行显示的本次 `.log` 文件。** 定位、验证和边界见 [排查日志与专业引线分类修复](docs/排查日志与专业引线分类修复-2026-10-13.md)。

## 覆盖与保留范围

处理模型空间、布局、本图块定义和动态匿名块、普通文字样式、文字、属性、标注、公差、引线、多重引线及普通表格内容。锁定图层按需临时解锁并恢复。

外参及依赖样式、形文件样式、标注/表格显示缓存不改写。无法解析的专业或代理对象列入“未覆盖”。

为保留原始关联，含字段且需要改局部字体的宿主、表格字段/公式/数据链接/锁定内容会保留原状并报告“部分完成”；其引用的本图文字样式仍可转换。表格内容枚举不明确或接口读取失败时停止，不把失败当成枚举结束。

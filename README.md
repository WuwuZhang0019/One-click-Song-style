# 一键统一宋体（YJST）

日期：2026-10-14

许可证：[MIT](LICENSE)，Copyright (c) 2026 张裕锋。
状态：v0.2.17 已修复字段反应器引用误判；原生 CAD 待复测

将当前 DWG 的普通文字样式和可处理的局部字体统一为宋体（SimSun），保留其他格式。不自动保存，不修改 `SECURELOAD`、`FONTALT`、`FONTMAP` 或 `LISPSYS`。

## 使用

已发布版下载：[v0.2.10 Release](https://github.com/WuwuZhang0019/One-click-Song-style/releases/tag/v0.2.10)，附件名为 `one-click-simsun-v0.2.10.lsp`。本次 v0.2.17 调整尚未发布，仓库内交付路径如下。

1. `APPLOAD` 加载 **`output/gb2312/YJSTFIX-v0.2.17.lsp`**，确认显示 **v0.2.17** 和诊断标识 **`2026-10-14-field-font-v9`**。加载仅注册命令。
2. 输入 **`YJSTFIX`** 转换当前图纸。工具集 `YJST` 仍会加载其内置的旧文件；若旧文件已覆盖当前版本，`YJSTFIX` 拒绝执行并提示重新加载。转换保留必要的写入读回、再生和回滚校验，命令行显示汇总、错误及最终成功/失败提示。转换不自动进行额外天正字体核查。
3. 成功转换后，一次 `U` 撤销本次修改；无需修改时不会新增撤销分组。
4. 需要天正公开字体核查时输入 `YJSTCHECK`。命令只读扫描当前图纸，不修改字体，也不要求先运行 `YJST`。输出通过、不一致、无法核验及错误数量；完整明细保留在本地日志。
5. `YJSTLOG` 显示最近一次转换或核查的日志路径。转换报告为 `*OCS:LastReport*`，核查报告为 `*OCS:LastCheckReport*`。
6. 转换或核查结束时显示“总耗时：xx.xx 秒”，失败运行也显示耗时；日志 `RUN_TIMING` 及报告的 `elapsedSeconds`、`phaseTimes` 保留总耗时与阶段用时。
7. 最终输出署名：`by张裕锋-20261013`。

根目录文件是 UTF-8 开发源码；目标 CAD 使用 GB2312 交付版。若之前从其他目录加载，请替换那份文件并重新 `APPLOAD`，以命令提示的版本号为准。

独立命令文件在初始化前检查已有运行状态和未关闭的撤销标记；转换仍会预检外部撤销分组，冲突时在写入前停止。普通 `output/gb2312/one-click-simsun.lsp` 同样注册 `YJSTFIX`，不自动转换。上一轮 `RUN-YJST-v0.2.12.lsp` 自动转换入口已停用，仅显示迁移提示。工具集安装包尚未更新。

## 排查日志

- 每次运行自动生成独立的 `YJST-*.log`，开始和结束均显示完整路径。输入 `YJSTLOG` 可再次查看路径。
- 日志记录环境与图纸名、扫描阶段、块名、对象类型、句柄、图层、接口调用前后、原始错误、回滚和最终状态。普通读取日志每 64 条写入并关闭文件；错误、阶段计时、回滚及结束立即落盘，写入接口前刷新缓冲。CAD 进程被强制终止时，最后不足一批的普通读取日志可能未落盘。
- 块引用 `Name` 读取失败时增加 `BLOCKREF_DIAG_*` 证据；`RUN_BEGIN` 和加载提示包含诊断标识。每项探测区分成功、返回空值、接口错误和缺少实体，读取前后立即关闭日志文件，不再重新构造对象或读取 ActiveX 属性。
- 原 `YJST-D5-CHECK-20261014.lsp` 自动探测版已撤回，当前同名文件仅提示停用。新独立入口为 `output/gb2312/tests/native/YJST-D5-DXF-20261014.lsp`，APPLOAD 仅注册命令；输入 `YJSTD5DXF` 才用 `handent`/`entget` 读取 D5，生成 `YJST-D5-DXF-*.log`。当前标识 `YJST-D5-20261014-v3-DXF` 修复空返回值触发 `symbolp nil` 的日志格式化错误，并区分 DXF 为空和接口报错。每次原生读取前先写入并关闭日志；无法写入日志时停止目标对象读取。原生崩溃后的日志只能定位最后进入的调用，不能凭模拟回归保证原图不再崩溃。
- `TDbSymbMultiLeader` 不再调用普通引线 Annotation 接口；可通过 `YJSTCHECK` 按公开数据只读核验。未覆盖及核查明细保存在日志中，命令行只显示汇总。

日志优先写入 CAD 的 `TEMPPREFIX`，失败后尝试系统 `TEMP` 和图纸目录。每次新建，保留之前的文件；文件名不会被 CAD 的临时文件机制自动删除。日志写入失败时，`YJSTLOG` 显示最近 40 条内存记录及日志错误，不覆盖原始业务错误。

日志优先使用 UTF-8；旧 CAD 不支持编码参数时自动使用引擎原有文本编码，并在日志开头标记 `CAD-legacy`。无需修改 CAD 系统变量。

**若仍报错，发送命令行显示的本次 `.log` 文件。** 定位、验证和边界见 [排查日志与专业引线分类修复](docs/排查日志与专业引线分类修复-2026-10-13.md)。

## 覆盖与保留范围

处理模型空间、布局、本图块定义和动态匿名块、普通文字样式、文字、属性、标注、公差、引线、多重引线及普通表格内容。锁定图层按需临时解锁并恢复。

外参及依赖样式、形文件样式、标注/表格显示缓存不改写。无法解析的专业或代理对象列入“未覆盖”。

为保留原始关联，含字段且需要改局部字体的普通文字宿主会保留原状并报告“部分完成”。表格字段/公式/数据链接/锁定内容同样保持原状，按下述只读核验结果决定是否计入未覆盖；其引用的本图文字样式仍可转换。表格内容数量不明确时保留局部字体并报告未覆盖；修改计划中已知内容的接口读取失败时停止写入，不把失败当成枚举结束。

受保护表格单元格只读核验通过后不计入未覆盖；字段表达式不改写，也不主动求值。当前支持 `_text` 包装字段和具有成功求值数值缓存的 `AcExpr` 子项；未知求值器、块内容、缺失或循环引用、未适配的多字段结构及读取异常均报告无法核验。核验范围是当前公开字体与显示内容，不能证明公式计算正确或未来结果不变。普通文字宿主的字段保护规则保持原范围。

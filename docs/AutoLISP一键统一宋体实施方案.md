# AutoLISP 当前图纸一键统一宋体实施方案

日期：2026-10-12

状态：可执行方案，待代码实现与原生 AutoCAD 验收

目标：在 Windows 完整版 AutoCAD 中执行一条 `YJST` 命令，将当前 DWG 中的文字字体统一为宋体，覆盖模型空间、全部布局、图块及属性，保留字高和字体以外的格式，暂不处理外部参照。

## 1 实现范围与使用方式

首版使用 AutoLISP 与 Visual LISP/ActiveX，交付一个可用 `APPLOAD` 加载的 `one-click-simsun.lsp`。加载后执行 `YJST`，程序自动检查字体、处理当前图纸、再生并输出结果，不要求逐个选中文字，不增加逐项确认窗口。

`YJST` 是本方案确定的待实现命令，目前尚未提供可运行的插件文件。具体支持的 AutoCAD 版本以阶段 S01 的验证结果为准，不提前承诺版本范围。

### 纳入处理的内容

| 范围 | 首版处理要求 |
| --- | --- |
| 模型空间与全部布局 | 包括当前未显示的布局，以及关闭、冻结、锁定图层中的本图文字 |
| 文字样式 | 修改本图可写文字样式，包括 `Standard`、注释性样式和未使用的普通文字样式 |
| 单行与多行文字 | 覆盖 `TEXT`、`MTEXT`，处理多行文字的局部字体覆盖 |
| 图块 | 覆盖普通块、嵌套块、未插入的本图块定义、动态块原始定义和当前匿名表示 |
| 属性 | 覆盖 `ATTDEF`、已有 `ATTRIB`，以及多行属性和常量属性 |
| 标注与公差 | 检查文字样式引用、标注文字覆盖、公差文字中的字体设置 |
| 引线与多重引线 | 普通引线的关联文字、多重引线文字内容，以及块内容引用的本图块和属性 |
| 表格 | 检查表格使用的文字样式、单元格及内容项的局部字体格式 |
| 字段宿主 | 修改宿主的字体，保留字段表达式、格式和对象关联 |

### 本阶段不处理的内容

- 外部参照的块定义、依赖样式及参照源文件。按已具备打开权限的前提保留后续扩展可能性，本阶段不打开、绑定、重载或改写源文件。
- PDF、图片、OLE、已炸成线条或轮廓的文字。
- `SHAPE` 及形文件记录；它们不是本方案要改的文字字体记录。

天正等专业实体和代理对象需要检测并记录。若其内部文字无法通过当前接口读取，报告列为未覆盖对象，不自动炸开，也不将其计入已完成的文字。

### 字体统一策略

保留原文字样式名称及现有引用关系，只替换样式的字体定义；对象内部存在字体覆盖时，将该覆盖指向宋体。首版不创建一套新的业务文字样式，不清理原样式，不建立多字体替换配置表。

宋体字体族以 `SimSun` 为目标，接受经验证的本地化名称“宋体”。`NSimSun`、`SimHei`、`STSong` 不作为自动替代。字体文件标识及字符集参数必须经目标 CAD 解析验证，不能把一个固定 `.ttf` 或 `.ttc` 文件名当作所有版本的通用结果。[Microsoft 宋体字体说明](https://learn.microsoft.com/en-us/typography/font-list/simsun)

## 2 格式保留与允许变化

“保留其他格式”指保留用户设置和数据语义，并不保证更换字体后的字形宽度、自动换行或包围盒完全相同。宋体与原字体的字符度量不同，可以出现换行和占用空间变化，程序不通过缩小字高、压缩宽度或移动文字自动消除这些变化。

| 类别 | 必须保留的内容 |
| --- | --- |
| 样式参数 | 固定字高、宽度因子、倾斜角、反向和倒置设置、注释性状态及相关比例语义 |
| 对象参数 | 字高、宽度因子、旋转、对齐方式和对齐锚点、图层、颜色、线型、线宽、透明度 |
| 多行文字 | 字高覆盖、宽度覆盖、字距、段落、缩进、行距、显式换行、堆叠分数、上下划线、颜色、背景遮罩、列设置 |
| 字体样式 | 原有粗体、斜体意图；更换字体后具体笔画表现由宋体及 CAD 渲染决定 |
| 属性与图块 | 属性值、标签、提示、可见性、属性顺序、块插入位置、比例、旋转、动态参数和可见性状态 |
| 标注 | 测量关联、标注样式名称、字高、数值格式、前后缀、公差、`<>` 与 `[]` 占位符、箭头及尺寸线设置 |
| 表格 | 数据类型、数值、公式、字段、数据链接、合并关系、行高、列宽、边框、填充和对齐设置 |
| 字段与扩展数据 | 字段对象、表达式、格式、引用关系，以及与字体修改无关的扩展字典、XData 和其他记录 |

允许修改的内容限定为主字体、大字体关联、字体描述中的目标字体参数，以及文字内容中的有效字体切换指令。粗体、斜体参数继续保留；字体族对应的字符集和 pitch/family 参数按照经过验证的宋体定义设置。

对齐文字在再生时可能重算内部位置，检查重点是用户定义的对齐锚点和对齐语义。`Fit`、`Aligned`、竖排、镜像和注释性对象应单独验证；不能为了让字体替换成功而修改其字高或对齐方式。

自定义 SHX 字形、私用区字符和罕见字符可能缺少宋体对应字形。保留原字符内容，并在验收中检查字形；不得把丢失字形当作文字内容已正确转换。

## 3 字体设置与大字体清空

### 检测与参数来源

1. 读取当前 AutoCAD 版本、平台和 AutoLISP 引擎信息。
2. 确认 Visual LISP/ActiveX 可用，检测宋体字体族及可解析的字体文件标识。
3. 可读取已正确使用宋体的本图样式作为参数参考，但应核对字体族，不能以当前显示正常作为唯一证据。
4. 对首次没有参考样式的环境，在受控试验中验证宋体字体族、文件标识、字符集、pitch/family 和大字体清空路径。
5. 宋体缺失、字体解析失败或关键接口不可用时，在业务写入之前停止，输出原因，不静默采用其他字体。

字体检测时可以使用解析后的绝对路径；持久化到样式时优先使用目标 CAD 已验证能解析的字体标识，避免写入某台电脑独有的绝对路径。文件是否能被 `findfile` 找到不能单独证明最终字体族正确。

### 写入步骤

`FontFile` 与 `SetFont` 一并处理。Autodesk 建议同时修改字体文件和字体族名称，以避免字体替代后名称没有正确更新。[FontFile 属性](https://help.autodesk.com/cloudhelp/2024/ENU/AutoCAD-ActiveX-Reference/files/GUID-DD2E1EB8-3BDE-46B6-ADC4-636234CCB3E7.htm)、[SetFont 方法](https://help.autodesk.com/cloudhelp/2016/CHS/AutoCAD-ActiveX/files/GUID-DB668114-2395-43C6-858C-2F2514C4BF46.htm)

大字体清空不能直接依赖 `vla-put-BigFontFile` 写入空字符串，ActiveX 文档不支持这一输入。候选路径为通过 `tblobjname` 和 `entget` 定位 `STYLE` 记录，将 DXF 组码 `4` 设为空，再用 `entmod` 写回；实际顺序、返回值和再生后的状态由 S01 验证。[BigFontFile 属性限制](https://help.autodesk.com/cloudhelp/2024/ENU/AutoCAD-ActiveX-Reference/files/GUID-6351C267-2821-4156-ACDB-603B22310872.htm)、[STYLE 记录定义](https://help.autodesk.com/cloudhelp/2018/ENU/AutoCAD-DXF/files/GUID-EF68AF7C-13EF-45A1-8175-ED6CE66C8FC9.htm)

最终必须读回以下结果：字体族为宋体、大字体为空、原字高和其他保留参数一致。写入时不改动与字体无关的 DXF 项，不清空整个 XData，也不通过重建样式丢弃未知记录。

### 样式过滤

- `STYLE` 的组码 `70` 中位值 `1` 表示形文件记录，位值 `16` 表示外部参照依赖记录，应跳过并分类记录。
- 不根据样式名称包含 `|` 作为唯一判断依据；应结合依赖标志和对象所属块判断。
- `Standard` 和注释性文字样式照常处理；未使用的普通样式照常处理，清理不属于本次命令。
- 原样式具有竖排设置时，先验证宋体竖排表示与原布局能否兼容；不能擅自清除竖排标志。[STYLE 标志定义](https://help.autodesk.com/cloudhelp/2018/ENU/AutoCAD-DXF/files/GUID-EF68AF7C-13EF-45A1-8175-ED6CE66C8FC9.htm)

## 4 当前图纸与图块遍历

以当前文档的 `Blocks` 集合为主要入口，遍历模型空间、每个布局块及本图块定义。仅靠 `ssget "_X"` 不足以覆盖块定义和各类文字宿主。

具体遍历规则：

1. 本图块记录按句柄去重，每个定义扫描一次；不因它当前未插入、所在图层不可见或名字以 `*` 开头而一概排除。
2. 遇到外部参照块，停止进入该定义；不跨到外部数据库处理。
3. 普通块定义中的文字和 `ATTDEF` 按实际对象处理。修改定义会影响图纸中的各个实例。[entmod 对块定义的影响](https://help.autodesk.com/cloudhelp/2019/ENU/AutoCAD-AutoLISP-Reference/files/GUID-C7D27797-247E-49B9-937C-0D8C58F4C832.htm)
4. 对每个本图块引用另外读取已有属性实例；可编辑属性通过 `GetAttributes` 获取，常量属性通过定义和实际可用的 `GetConstantAttributes` 接口检查，按句柄去重。
5. 动态块同时扫描原始定义和已生成的匿名表示，记录它们的关联。保持动态参数、可见性状态和现有属性值，不调用 `ResetBlock`、`ATTSYNC` 或 `EXPLODE` 进行强制刷新。
6. 标注、表格等对象生成的匿名显示块交给其源宿主处理，不把修改显示块中的文字作为持久化方案。匿名块需要按来源分类，不能统一跳过，也不能统一直接改写。[匿名块说明](https://help.autodesk.com/cloudhelp/2026/DEU/AutoCAD-AutoLISP/files/GUID-EB9BFDAA-487A-4586-A556-1F5F84BCF2F3.htm)
7. 发现未知专业对象时记录类型、句柄和块或布局位置；其内部文字无法读取时保留为覆盖缺口。

按数据库对象数量报告扫描和修改数量，不把修改一个块定义中的文字重复计为每个可见实例都执行了一次写入。

## 5 局部字体格式处理

### 解析规则

使用逐字符扫描器处理文字内容，识别字体切换指令、转义、花括号作用域和字段范围。扫描器是独立纯函数，不直接访问 CAD 对象。

必须满足以下规则：

- 识别字段范围之外的有效 `\f`、`\F` 字体切换，不依赖全局字符串替换。
- 普通文本中的字体名称保持原文，例如“本页统一使用黑体”不能改成“本页统一使用宋体”。
- 字体族改为宋体，保留已有粗体、斜体意图，其余字体描述参数按照验证过的目标字体规则处理。
- 保留 `\H`、`\W`、`\T`、`\Q`、`\C`、`\c`、`\P`、`\p`、`\S`、上下划线和合法转义的原有语义。
- `%<...>%` 中的字段表达式作为独立范围保护；其中的 `\f` 可能表示日期或数值格式，不是文字字体切换。[FieldCode 方法与字段示例](https://help.autodesk.com/cloudhelp/2022/CHS/AutoCAD-ActiveX-Reference/files/GUID-FE0C5004-B723-4AE8-888A-7DF11C765C89.htm)
- 支持嵌套格式和嵌套字段，保持文字字符及显式换行顺序。
- 大段文字需要完整读写，不只读取一个 DXF 组码 `1`；选择经过长文本往返验证的宿主接口或完整分段序列。
- 遇到不能可靠解析的字体指令，记录位置和原因，不能通过删除整段格式继续报成功。

保留一个原有字体覆盖并将其字体族改为宋体，比直接删除该覆盖更容易保留粗体和斜体作用域。没有字体覆盖的文字继续继承修改后的原样式，不额外添加字体指令。

### 扫描器验证样例

以下是原始文字内容的示意，不是可直接运行的 AutoLISP 字符串；写入测试代码时应按语言规则转义反斜杠。

| 输入类别 | 验证要求 |
| --- | --- |
| 普通文字与样式继承 | 内容原样，不增加格式代码 |
| 指定 Arial 且带粗体和斜体参数的字体段 | 字体族替换，粗体和斜体意图保留 |
| `\H0.7x;` 与嵌套字体段 | 字高覆盖保持，正确识别各段字体 |
| `\P`、段落缩进与行距 | 段落格式及显式换行保持 |
| `\S1/2;`、直径和公差符号 | 堆叠结构与字符保持 |
| 字段表达式中的 `\f` | 字段代码与格式保持，不能改成字体指令 |
| 转义反斜杠、花括号及中文 | 不误识别为格式开关，字符不丢失 |
| 超过 1000 字符的中英混合内容 | 完整往返，不截断；第二次处理结果完全相同 |
| 已经使用宋体的内容 | 不产生有效修改 |
| 不完整格式指令 | 返回可定位的解析错误，不返回伪造的成功内容 |

以下原始内容应作为嵌套格式用例：替换两个字体族，保留 `b1`、`i1`、`\H0.7x;`、`\P` 和各段花括号作用域。目标字体的其他描述参数按 S01 验证结果生成。

```text
{\fArial|b1|i0;标题}\P{\H0.7x;\fSimHei|b0|i1;说明}
```

## 6 各文字宿主的处理约定

| 宿主 | 实现与读回要求 |
| --- | --- |
| `TEXT` | 主要通过原样式更新字体，保持文字字符串和对象参数；有字段时同时检查 `FieldCode` 与字段关联 |
| `MTEXT` | 读取完整原始内容，处理字体指令，保持段落和字段；写回后比较非字体格式和字段关联 |
| 单行属性 | 检查定义与实例，不重置属性值、标签、提示和可见性 |
| 多行属性 | 使用 `MTextAttributeContent` 读取和写回，并按对象支持情况调用 `UpdateMTextAttribute`；核对多行内容、边界宽度和属性值 |
| 标注 | 修改使用的文字样式；局部覆盖通过 `TextOverride` 等实际宿主接口处理，保持测量关系、占位符、前后缀和公差 |
| 公差 | 检查其文字样式引用和可读文字内容，保留公差符号及关联语义 |
| 普通引线 | 处理关联注释对象，不只检查引线本身；保持引线与注释关联 |
| 多重引线 | 文字内容检查 `TextString` 及文字样式引用；块内容处理其本图块和实际属性，不把多重引线样式名称当作文字样式名称 |
| 表格 | 按单元格与内容项处理字体，保留数据类型、字段、公式、数据链接及格式；禁止将显示值写回为普通字符串 |

多行属性的接口和同步方法见 [MTextAttributeContent 属性](https://help.autodesk.com/cloudhelp/2022/ENU/AutoCAD-ActiveX-Reference/files/GUID-9D15CA00-A962-4664-9BE5-81C43384478C.htm) 和 [UpdateMTextAttribute 方法](https://help.autodesk.com/cloudhelp/2016/CHS/AutoCAD-ActiveX/files/GUID-73942896-D842-4ED6-B205-39D3CA9E4076.htm)。标注文字覆盖需要保留计算值占位符，见 [TextOverride 属性](https://help.autodesk.com/cloudhelp/2024/CHS/AutoCAD-ActiveX-Reference/files/GUID-B2576004-E3DA-4E90-9E5B-0DB166AAD008.htm)。

不能把所有对象的 `StyleName` 设置为“宋体”：该属性在标注、表格、多重引线等对象上对应各自的业务样式。首版保留业务样式名称和引用，只更换所引用文字样式的字体，另行处理字体覆盖。[StyleName 属性](https://help.autodesk.com/cloudhelp/2024/FRA/AutoCAD-LT-ActiveX-Reference/files/GUID-F70A2F76-B986-4742-9863-4A9693C8DA0A.htm)

表格适配必须区分普通文本、字段、公式、块内容和数据链接。`GetTextString`、`SetTextString` 具有内容项参数，不能假设每个单元格只有内容项 `0`。内容数量与有效索引应从该版本可核验的表格数据结构或实际可用接口获取，不能将空字符串或一次读失败当作遍历终点；无法确认完整覆盖时，阻止表格阶段通过验收。[GetTextString 方法](https://help.autodesk.com/cloudhelp/2017/DEU/AutoCAD-ActiveX/files/GUID-16DC0D7E-708E-44B4-9A59-1BDEFCA76A3D.htm)、[SetTextString 方法](https://help.autodesk.com/cloudhelp/2020/ENU/AutoCAD-ActiveX-Reference/files/GUID-C5887D04-EB95-4311-A44F-D7046C3085E9.htm)

表格修改时可以暂时抑制重复再生，完成后恢复原状态并统一更新；不得遗留 `RegenerateTableSuppressed` 设置，也不得调用清除全部格式覆盖的方法。[Table 对象说明](https://help.autodesk.com/cloudhelp/2026/ENU/AutoCAD-ActiveX-Reference/files/GUID-7B82400C-53D0-4D1A-94FA-66BB3040F0AA.htm)

## 7 撤销 恢复与状态保留

正常执行以一个 Undo 分组包含全部写入，使用 `StartUndoMark` 与 `EndUndoMark`，并验证一次 `U` 能恢复原图。Undo 分组只负责组织撤销，不能代替异常回滚设计。[StartUndoMark 方法](https://help.autodesk.com/cloudhelp/2026/DEU/AutoCAD-ActiveX-Reference/files/GUID-7C669949-1327-4CFD-96CF-CE65EC38DAA8.htm)

执行前记录计划修改的样式、文字宿主和字段数据，以及需要临时修改的图层锁定状态、表格再生状态和系统变量。非字体格式的快照用于写后检查，不依赖肉眼判断格式是否保留。

锁定层中的本图文字也属于目标范围。按需要暂时解锁相关本图图层，完成或异常时恢复；图层开关、冻结状态和当前图层保持。外部参照相关图层保持原状。修改共享文字样式本来就会影响锁定层，不能仅因实体没有写入而声称锁定层已被排除。

错误处理约定：

- 字体预检失败、图纸不可修改、撤销不可用或处于不兼容编辑上下文时，在业务写入前退出并说明原因。
- 标准对象写入失败、写后检查不一致、字高或非字体格式改变时，中止本次操作并回滚，不继续将有问题的结果当作完成。
- Esc 进入与错误相同的收尾流程，恢复临时状态并回滚已经执行的业务写入。
- 回滚只作用于本次命令已经建立的分组，不能无条件执行 `UNDO Back` 或撤销用户上一条命令。异常处理中的命令调用方式、Undo 分组嵌套和中断时机由 S05 的原生试验确定。
- 回滚完成后读回核对；若恢复失败，输出独立失败状态及对象句柄，不覆盖原始错误，也不自动保存图纸。
- 尚未解析的专业对象保留为覆盖缺口，已成功处理的标准对象可以在报告中列出，但整体状态不能写成“全图所有文字完成”。

程序不自动执行 `SAVEAS`、不强制生成备份、不自动保存 DWG，不改 `FONTALT`、`FONTMAP`、`SECURELOAD` 或 `LISPSYS` 等环境设置。正常或异常退出后都应保留用户原有选择和编辑状态中可恢复的部分。

## 8 命令流程与函数职责

命令流程为：环境与字体预检，扫描并生成修改计划，开始 Undo 分组，按需保存和调整临时状态，应用样式修改，应用局部字体修改，恢复临时状态，再生当前图纸，读回检查，结束 Undo 分组，输出报告。任何中途错误进入回滚流程。

扫描阶段先判断所属范围，再读取和分类对象；只对需要修改的内容写入。按样式和对象句柄缓存信息，避免同一个块定义反复扫描。所有 CAD API 访问在命令上下文中串行执行，不引入后台线程或异步数据库写入。

| 函数 | 职责与返回结果 |
| --- | --- |
| `c:YJST` | 用户入口，协调预检、计划、写入、收尾和报告 |
| `OCS:Preflight` | 读取版本与环境，确认字体、关键接口、编辑状态和撤销条件 |
| `OCS:ResolveSongFont` | 返回经验证的字体族、文件标识、字符集及字体参数 |
| `OCS:CollectStyles` | 分类本图普通样式、外部依赖记录和形文件记录 |
| `OCS:CollectHosts` | 收集布局、块定义、属性实例及各类宿主，按句柄去重 |
| `OCS:NormalizeFontRuns` | 纯函数解析并修改有效字体段，返回新内容、修改数及解析问题 |
| `OCS:ReadHost` | 按对象类型读取原始内容、字体引用和必须保留的数据 |
| `OCS:BuildPlan` | 生成样式修改、内容修改、原始快照及未覆盖对象清单 |
| `OCS:ApplyStyle` | 应用宋体及大字体清空，保留样式其他参数并读回 |
| `OCS:WriteHost` | 使用对应宿主接口写回内容并检查字段、属性和格式 |
| `OCS:VerifyDrawing` | 再生后检查字体覆盖、字高、非字体格式、字段和临时状态 |
| `OCS:Rollback` | 仅回滚本次操作，恢复状态并返回恢复检查结果 |
| `OCS:Report` | 生成中文命令行摘要及可定位的详细记录 |

对象类型、路径及句柄使用稳定字符串表示；涉及 64 位 ObjectID 时不任意转换成 32 位整数。COM 返回的 Variant、SafeArray 和错误值统一解包，错误字符串不当作成功值。

保留 `*OCS:LastReport*` 作为最近一次运行的结构化结果，供调试与自动验收读取。它不用于在下次执行时跳过重新扫描当前图纸。

## 10 分阶段实施与完成条件

按 S01 至 S06 顺序执行。每个阶段通过对应检查后再进入下一个阶段，记录真实结果；阶段完成不等于插件已通过全部原生验收。

### S01 验证目标 CAD 与关键接口

- 记录目标 AutoCAD 版本、平台、AutoLISP 引擎、宋体字体族及文件解析结果。
- 验证普通 SHX、SHX 加 Bigfont、原有 TrueType、粗体斜体、竖排和注释性样式转换。
- 确认字体文件与字体族的写入顺序、大字体清空及读回方式。
- 对长多行文字、含字段文字、多行属性、表格普通内容和多内容项做原始内容往返试验。
- 确认动态块原始定义与匿名表示的读取路径，确认字段、公式和数据链接检查接口。

产物：字体参数与接口结论、最小试验代码、`docs/AutoCAD验收记录.md` 初始环境记录。

完成条件：至少一个明确的目标 CAD 版本通过字体转换与关键数据往返试验。若有字段或表格内容无法安全读写，先解决该适配问题，不把后续实现建立在未验证的显示值回写上。

### S02 实现字体格式扫描器

- 建立 `font-format-cases.json`，覆盖第五节样例与嵌套字段。
- 实现 `OCS:NormalizeFontRuns`，将字段代码与非字体格式作为必须保留的数据。
- 检查完整往返、错误定位和第二次运行零修改。

产物：纯解析函数、可重复运行的检查入口和样例结果。

完成条件：字体覆盖被正确替换，文字字符、字段代码和非字体格式一致，长文本不截断，异常指令可定位。

### S03 实现样式与图块覆盖

- 实现样式收集、外部依赖过滤、宋体写入和大字体清空。
- 实现全部布局、本图块定义、动态块表示及属性实例收集。
- 实现 `TEXT`、`MTEXT`、单行属性和多行属性适配。
- 保护样式名、属性值、动态参数、字高和其他格式。

产物：`one-click-simsun.lsp` 的样式与图块功能，以及 S03 原生检查结果。

完成条件：嵌套块和各布局中的文字能转换，已有属性值保持，动态块切换状态后仍使用宋体，外部参照样式和源文件保持原状。

### S04 实现标注 引线与表格

- 实现标注、公差、普通引线及多重引线文字适配。
- 实现表格内容分类、有效内容项枚举和局部字体处理。
- 保留字段、公式、数据链接、表格尺寸和原格式覆盖。
- 再生标注和表格时，通过源宿主更新，检查字体不会恢复。

产物：完整的标准文字宿主适配及 S04 原生检查结果。

完成条件：第六节全部宿主均通过真实样例，表格的多内容项完整覆盖，测量关联和数据语义保持；没有用显示值替换字段或公式。

### S05 实现单命令 撤销与异常恢复

- 完成 `YJST` 命令流程、版本与字体预检、修改计划和中文报告。
- 实现锁定层与临时状态恢复、写后检查、一次撤销和错误回滚。
- 在样式写入、内容写入和再生检查等时点注入故障，并测试 Esc。
- 检查重入、已有 Undo 分组、撤销不可用、字体缺失和不可写对象等情况。

产物：可加载的单文件插件、恢复检查结果与可定位报告。

完成条件：正常执行无需逐项确认；一次 `U` 恢复本次操作；错误和 Esc 不遗留业务修改或临时状态；恢复失败能准确报告。

### S06 完成真实图纸验收与交付

- 在验收矩阵和实际用户 DWG 上执行 `YJST`。
- 检查字高和其他格式，再次执行确认零有效修改。
- 保存、关闭、重新打开图纸后复查，切换动态块状态和注释比例，更新字段与数据链接。
- 检查打印预览和导出的 PDF，不修改图纸的打印配置。
- 更新支持版本、使用步骤、已知覆盖缺口及验收记录。

产物：`one-click-simsun.lsp`、实际验收记录及用户加载说明。

完成条件：目标版本和实际图纸的结果可核验，标准文字均为宋体，保留项一致，外部参照保持原状，未覆盖专业对象有明确记录。

## 12 结果报告与完成判定

正常结果至少报告：当前 DWG、CAD 版本、目标字体族、扫描样式数、修改样式数、扫描文字宿主数、修改字体段数、扫描块定义数、属性实例数、表格内容项数、外参跳过数、专业对象未覆盖数和错误数。

详细记录使用对象类型、句柄、所属布局或块、表格行列及内容项、原因码和必要的原始错误。字段和属性值无需在默认命令行摘要中完整输出。

| 状态 | 判定 |
| --- | --- |
| 已完成 | 范围内文字字体与保留项检查通过，未覆盖数和错误数均为零 |
| 无需修改 | 本次扫描没有有效字体修改，保留项及覆盖检查通过 |
| 部分完成 | 标准对象处理通过，但存在专业对象内部文字无法解析等覆盖缺口 |
| 已取消并回滚 | 用户取消后本次业务修改和临时状态恢复通过 |
| 失败已回滚 | 写入或检查失败，本次操作恢复通过 |
| 恢复失败 | 本次数据或临时状态无法确认已恢复，需要依据记录处理 |

外部参照、PDF、图片、OLE 和线条文字属于用户明确排除范围，其跳过不计入本图标准文字的完成缺口。凡存在范围内对象未处理、字段关联损坏、字高或其他格式改变，不得报告“当前图纸所有文字已统一宋体”。

## 13 开始实施前的执行顺序

首先执行 S01，确认实际目标 CAD 版本及字体、字段、表格和动态块接口。随后按 S02、S03、S04、S05、S06 依次实现和验证。每个阶段将结果写入带日期的验收记录，并同步更新阶段进度。

本方案的实现目标固定为：一条命令处理当前 DWG、本图图块文字必须覆盖、字体以外的数据与格式保留、外部参照暂不处理。若某个接口不能满足格式保留，先解决适配或记录具体未通过项，不以删除格式、炸块或缩小处理范围替代目标。

# 一键统一宋体 v0.2.9

日期：2026-10-13
状态：发布版本；独立核查命令原生 CAD 待复测

## 更新

- 新增 `YJSTCHECK`：用户主动输入时，只读核查当前图纸中的天正公开字体引用与可读内容。
- `YJST` 直接转换，不再自动执行额外天正核查；保留写入读回、再生校验和失败回滚。
- 命令行不再逐条打印未覆盖对象及核查问题清单；完整明细仍写入本地日志。
- 增加最终成功或失败提示；部分完成、无法核验和回滚情况明确区分。
- 修复天正 `TDbDimension2` 被误当普通标注调用 `TextOverride` 的错误，并收紧相关对象分类。
- 补充历史错误修复、现场复核和天正核查文档。

## 使用

下载本 Release 附件 `one-click-simsun.lsp`，在 CAD 中 `APPLOAD` 加载，确认 v0.2.9。

- `YJST`：字体转换。
- `YJSTCHECK`：按需天正公开字体核查，不修改图纸。
- `YJSTLOG`：显示最近一次运行的日志路径。

附件编码为 GB2312，供目标旧版 CAD 加载；仓库根目录源码为 UTF-8。无需上传图纸或导出 DXF，不自动保存图纸。

## 验证与范围

19 项定向回归、源码静态检查、严格 GB2312 编码往返与交付读取检查通过。已有 v0.2.7、v0.2.8 大图现场日志确认执行无错误；v0.2.9 独立命令与实际耗时待原生 CAD 复测。

支持公开核查天正文字、多行文字、图名和多重引线；无法完整读取的结构明确报告无法核验。天正标注、其他专业对象私有数据、保存重开及打印效果未全部覆盖。“执行成功”不等于全部专业对象内部都已核验。

# YJST 执行错误修复

日期：2026-10-13
状态：v0.1.1 已修复已定位的执行链错误；源码回归通过，目标 CAD 原图待复测

## 直接原因

截图显示文件加载成功，输入 `YJST` 后报“参数太多”。原来的 `OCS:getVal` 定义只接受 `(res key)`，`OCS:mainFlow` 却调用 `(OCS:getVal pre "ok" nil)`。全文件共发现 29 处自定义函数参数数量不匹配，包括过多的 `getVal` 参数与缺少缺省值的 `assocd` 调用。

这属于源码错误，不能从该报错推断字体安装、文件编码或 CAD 厂商有问题。

## 同一执行链中的修复

- 固定取值函数为三个参数，统一全部调用；按键值对遍历 plist，避免把值误当键；数字键按 DXF 点对读取。
- 补齐 22 个函数中遗漏的局部变量，避免 AutoLISP 动态作用域导致调用方变量被覆盖；不再把常量 `T` 当作变量使用。
- 使用真实的 `:vlax-true` / `:vlax-false`，按 Block 自身的 `Count` / `Item` 遍历实体，正确解包 Variant/SafeArray；动态匿名块 `*U` 不再误跳过。
- 扫描器接受英文字体名；分号结束字体描述，竖线分隔符正常推进；字段范围完整保留且不重复其后字符；不完整字段/字体码明确报告问题。
- 临时样式使用未占用名称并用 ActiveX 删除；GetFont 验证实际字体族；转换样式保留原粗体/斜体；二次运行跳过已经符合要求的样式。
- 明确比较错误数是否大于零，避免 AutoLISP 把 `0` 当真导致成功也回滚；捕获错误后先保存原始错误信息；异常收尾释放命令运行标记。
- 写入文本后校验对应属性；仅在本次撤销分组存在且已有成功写入时执行一次 `command-s "_.U"`。正常命令返回 nil 不再被误判为失败。
- 输出三个执行阶段，保留 `*OCS:LastReport*`；普通几何对象不再误计为文字未覆盖，表格单元格局部字体缺口明确列为“部分完成”。

接口依据：[Autodesk SetFont](https://help.autodesk.com/cloudhelp/2020/CHT/AutoCAD-ActiveX-Reference/files/GUID-DB668114-2395-43C6-858C-2F2514C4BF46.htm)、[GetFont](https://help.autodesk.com/cloudhelp/2016/CHT/AutoCAD-ActiveX/files/GUID-7070FBED-AD5F-47EB-BB9A-5CD25B76DCC8.htm)、[Block 对象](https://help.autodesk.com/cloudhelp/2022/ENU/AutoCAD-ActiveX-Reference/files/GUID-E6F7B03B-F5CC-4A18-9C48-BBF1D32A31FD.htm)。原代码的 `2 | 16 | 4` 实际为 22（0x16），不是 36（0x24）；实际字体效果仍以目标 CAD 读回为准。

## 验证

原检查器只核对括号和 JSON 预期的一致性，并未执行扫描器。因此新增有限解释器，直接执行仓库 LISP 函数体，采用 AutoLISP 的动态作用域和真值语义；未支持的函数直接失败。CAD 接口由独立测试替身提供，不能把它当原生引擎。

执行命令：

```powershell
python -X utf8 tools/test_lisp_runtime.py
python -X utf8 tools/check_lisp.py
python -X utf8 tools/build_gb2312.py
python -X utf8 tools/test_build_gb2312.py
python -X utf8 tools/lisp_reader_probe.py output/gb2312/one-click-simsun.lsp
git diff --check
```

源码回归覆盖 18 项测试，其中包括 15 个扫描样例及再次运行检查、LISP 内置自检、实际主流程与模拟图纸首次/二次运行、外参跳过、动态块、锁定层、写入失败及静默写入失败回滚、空分组不得撤销之前操作。修复前检查实际重现了参数异常、扫描器不转换英文族名、DXF 取值失败等问题。

JSON 中两个声称为合法字段的样例原先缺少正确的 `>%` 结束标记，现已修正；另增加未闭合字段用例，仍要求报错且原文保持。已为 SimSun 的字体段按原约定保持原样，修正了原先要求重复补参数的错误预期。

GB2312 构建严格编码并校验往返，构建工具的 5 项测试通过；加载文件读入检查为 0 错误。UTF-8 开发源码与 GB2312 交付文件保持文本一致。

## 加载与复测

1. 将本项目的 `output/gb2312/one-click-simsun.lsp` 复制到实际使用 CAD 的电脑，替换之前加载的旧文件。截图使用的是 `H:/coding/...`，本次工作区是 `G:/rust/AI画CAD/One-click Song style`，不是同一个文件路径。
2. `APPLOAD` 重新加载该文件，确认提示版本 **v0.1.1**，执行 `YJST`。
3. 在图纸副本核对宋体、字高/宽度/位置、块内文字和锁定层；再次执行应为零有效修改；另单独验证一次 `U`、Esc、保存重开和打印效果。
4. 若仍失败，F2 完整命令行应包含三个阶段提示及错误明细；连同 `(princ *OCS:LastReport*)` 输出用于继续定位。

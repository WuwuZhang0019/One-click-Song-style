最终规则：

1. 字体文件可用性预检、完整路径优先、英文族名失败后中文族名尝试均保留，不静默替换成 NSimSun、黑体或 STSong。
2. FontFile 与 DXF 3 均指向宋体文件，或二者均空且 GetFont 描述符正确，才可接受。两处不一致、非空错误文件、空族名仍拒绝。
3. 清大字体放在字体设置之前；设置完成后只读核对 DXF 和 COM，不能为“补全”某个字段再次破坏描述符。
4. 每个样式记录本轮通过验证的状态，最终再生要求绑定方式及原粗斜体稳定；原来有文件的绑定突然丢失不能事后改称另一种合法模式。
5. 所有阶段的真实异常仍停止并回滚。完整现场失败日志中的 `recoverFailed=0`，与没有发生错误时的“无需回滚”分别记录。

## 6. 本项目应保留的排查方法

- 先确认加载路径、版本、编码和交付文件身份。根目录 UTF-8 源码、H 盘历史文件、旧诊断分片都不能混作当前交付。
- 按加载、预检、扫描、临时试写、正式写入、再生和恢复区分错误；读取日志到 RUN_END，不能只看第一条报错。
- 先复现失败，再改最小相关路径；必须覆盖临时试写与正式修改，不能只绕过一个检查。
- 接口返回成功只是第一步，继续比较实际读回。FontFile、SetFont、entmod 会改变相关状态，调用顺序本身就是修复内容。
- 不把任意错误当空值或枚举结束；不把 0 当 false；不把字符串当 COM 布尔值；不将 plist 与 DXF 点对混用。
